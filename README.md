# Miyori Kitsune AI v1.1.0

Первый запускаемый каркас проекта **Miyori Kitsune AI**.

## Что уже работает

- локальный веб-интерфейс;
- запуск в Windows двойным кликом через `Miyori.bat`;
- запуск из любой папки, флешки или внешнего диска без фиксированной буквы диска;
- локальная SQLite-база `data/miyori.sqlite3`;
- сохранение сообщений диалога;
- серверный адаптер Cloud.ru Foundation Models;
- ключ Cloud.ru не отправляется в браузер и исключён из Git через `.gitignore`;
- отображение состояния настройки провайдера.

Текущая внутренняя версия приложения: **00.00.01**.

## Быстрый запуск на Windows

1. Скачайте или клонируйте репозиторий.
2. Установите Python 3.11+ и включите добавление Python в PATH.
3. Запустите `Miyori.bat`.
4. При первом запуске рядом появится файл `.env`.
5. Откройте `.env` и заполните `CLOUDRU_API_KEY` и `CLOUDRU_MODEL_ID`.
6. Снова запустите `Miyori.bat`.

Сайт откроется автоматически по адресу `http://127.0.0.1:8765`.

## Запуск с любого носителя

`Miyori.bat` начинает работу командой:

```bat
cd /d "%~dp0"
```

Поэтому путь не привязан к диску: проект можно держать на `C:\Miyori`, `D:\AI\Miyori`, USB-флешке или внешнем SSD.

Виртуальное окружение `.venv`, настройки `.env` и каталог данных `data` находятся рядом с приложением.

### Текущее ограничение переносимости

Сейчас на компьютере должен быть установлен **Python 3.11+**. Следующий уровень переносимости — положить собственный Python runtime внутрь проекта, чтобы `Miyori.bat` запускался даже на Windows без установленного Python.

## Ручной запуск

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python app.py
```

## Настройка Cloud.ru

Создайте `.env` из `.env.example` и задайте:

```env
CLOUDRU_API_KEY=...
CLOUDRU_MODEL_ID=...
CLOUDRU_BASE_URL=https://foundation-models.api.cloud.ru/v1
```

Ключ используется только Python-сервером. Браузер его не получает.

## Безопасность

- `.env` не коммитится;
- API-ключ не включён в клиентский JavaScript;
- локальные данные в `data/` не коммитятся;
- ошибка Cloud.ru не превращается в выдуманный ответ помощницы;
- пользовательское сообщение сохраняется до обращения к провайдеру.
